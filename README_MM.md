# DAMA APP — Native Android 1.1

Contains native Java Activities for Home, Radio, Library, TV, Daily Worship, Search, Settings and Menu.

Audio: 14 seed MP3 links, 22 source pages for optional runtime Sync. No third-party MP3 is redistributed in APK. Some links may be stale.

UI: dark midnight-teal / gold, matching the prior DAMA prototype theme. Android runtime rendering uses native views, not static screenshot pages.

Build with GitHub Actions or Android Studio (Java 17 / Android SDK 35).

The TV, books and worship external links open source publishers / YouTube. YouTube and MP3 playback require an Internet connection.

Important: An APK build and a phone startup test must be independently verified before production release.
