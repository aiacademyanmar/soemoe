# Soe Moe AI Trainer V2.1 — Native Website Content Catalog

This release **replaces the starter-content launcher** with a Compose-based native content explorer.
- Local archived source: website index.html and books.html (September 2026), provided by owner in connected Google Drive.
- Included: 20 website AI classes with syllabus and course outputs; 10 published book reviews/descriptions; 19 credential references; 9 AI portfolio entries; 13 project experience entries; 2 flagship programs; 4 featured-book entries; 23 archived page sections.
- Offline Android native screen/search/details. External original certificate and website links open using Android intents. No WebView.
- Teacher portrait app launcher icon remains Android adaptive PNG/XML.
- Not included: **complete book manuscripts**, account/registration database, certificates issuance, media files unavailable in archived HTML, and post-September website changes.

**Acceptance gate:** GitHub debug build and unit tests can pass without physical Samsung QA; physical QA NOT RUN, production BLOCKED. The website could not be live crawled, so this is not verified as a complete up-to-date website migration.
