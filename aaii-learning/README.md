# AAII Learning Native Android UI/UX V3.1
- Runs on Android 7.0+ with fixed 5-item native footer menu (outside ScrollView).
- 337 Courses with Burmese pedagogical guides (AAII-generated original explanations, **not** guaranteed up-to-date official module synopses), 37 Specializations, 18 Professional Certificate Programs.
- Program detail shows AAII course associations, roadmap, official Coursera original link.
- Teacher Roadmap links to verified Coursera courses (Arizona State University TESOL, UNSW Learning to Teach Online, University of London Get Interactive, UC Irvine Virtual Teacher, Commonwealth Education Trust).
- Important: a Coursera course certificate/TESOL certificate does not automatically grant a government teaching license.
- No private certificate IDs/links or private account details are published. Device-private import only.
- Branch is `aaii-learning-apk-v3-public`, app source under `aaii-learning/`, original Kid Creator main branch untouched.
- Build: GitHub Actions > AAII Learning - Native Android APK Public Build. If successful, download artifact `AAII-Learning-V3-Installable-APK` and install `app-debug.apk`.
- Coursera content and course arrangements may change. Visit each official course page for the current curriculum. No licensed media is redistributed.
