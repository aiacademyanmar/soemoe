# AAII Learning Android Build — First GitHub Repository
This dedicated folder `aaii-learning/` on branch `aaii-learning-apk-v3-public` builds a **real Java Native Android debug APK** in the original GitHub repository without changing its Kid Creator main project.

Build in GitHub Actions > "AAII Learning - Native Android APK Public Build", choose branch `aaii-learning-apk-v3-public` > Run workflow. Download artifact `AAII-Learning-V3-Installable-APK` after the workflow succeeds.

Public project includes 337 curated Coursera course names/links, 18 professional certificate roadmaps, teacher study plan and offline support. **Personal completed-course indicators and all 55 certificate IDs/URLs are intentionally excluded**. Do not commit private programs.json to this public repository. Import private programs.json locally in the app via Certificates > Import (Android file picker). The official issuing service remains Coursera; AAII does not issue accredited Coursera certificates.

Android 7.0+; Android Studio Gradle 8.9, JDK17, SDK35. APK is untested on a physical Android phone unless explicitly confirmed later.
