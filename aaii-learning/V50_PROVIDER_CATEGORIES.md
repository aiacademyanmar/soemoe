# AAII Learning V5.0 - Corporate & University Directory

Existing dataset (337 Courses, 55 Programs) sorted into Corporate/Companies 171 Courses, Universities 143 Courses, Learning Partners 23 Courses, covering 33 unique providers. Companies include Google, Microsoft, IBM, Meta, AWS, Google Cloud, Adobe, Palo Alto Networks. Universities are based on Coursera source provider strings; remaining specialized providers as Learning Partners. UI: Home logos and directory access, categorized provider directory, Courses & Specializations/Professional filter chips, course cards with provider icon and tap feedback. Source logos: Simple Icons `google.svg`, `meta.svg`, `googlecloud.svg`, https://github.com/simple-icons/simple-icons, CC0 icon shapes subject to respective brand trademark guidelines. Microsoft four-color square mark and Adobe stylized A are vector renditions; IBM/AWS are text labels, not official assets. Universities use generic campus icon, **not** actual institution emblems. No endorsement/official AAII corporate partnership is implied. Provider grouping is curated for local dataset, not full live Coursera catalog. Device UI testing pending.
