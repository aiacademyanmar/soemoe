# AAII Learning Native V4.0

Merged UI/UX design navigation into native Android: course catalog 337, specializations 37, professional 18, teacher education, Teacher Soe Moe profile, teacher booking request with native Date/Time pickers, enrollment assistance, local request drafts, private certificate import, study progress dashboard, profile/settings, and fixed footer.

Important: public source contains **no individual Coursera certificate IDs or personal verification URLs**. All request submissions are Share intents, never server confirmations. No realtime teacher availability, reviews or verified teaching licence claims. UI uses native Android Views and source remains independent from the originally depicted infographic design. Build must be verified by GitHub Actions before treating as an installable APK.
