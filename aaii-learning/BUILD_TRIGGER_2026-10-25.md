# AAII Learning — Android Native APK Build

This file changes only the `aaii-learning/**` path to trigger the GitHub Actions Android APK build on the `aaii-learning-apk-v3-public` branch.

Build source: Java Android. GitHub workflow: `.github/workflows/aaii-learning-apk.yml`.

This PUBLIC build intentionally contains no private Coursera accomplishment IDs, earned certificate links, or authentication tokens.
