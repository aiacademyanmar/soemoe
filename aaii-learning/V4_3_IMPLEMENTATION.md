# AAII Learning V4.3 — UI/UX and Navigation

This build includes a 7-item native fixed bottom navigation: Home, Courses, Specializations, Professional, Teachers, Services, Profile. New interactive native Services Hub (page 14) links to Enrollment Assistance, Hire a Teacher, Teacher Soe Moe profile, My Learning, private Certificate Wallet and local Request Drafts.

Polished navy/cobalt/gold header, gradient screen banners, interactive double service tiles, elevated cards and Native Android image portrait references. Course catalog 337, specializations 37, professional certificates 18 remain. Important: No personal Coursera certificate IDs in the public GitHub repository. Coursera account login and payment are not implemented; enrollment and booking require external manual confirmation.

This is an improved native layout, **not pixel-perfect identical** to 14 illustrated Full-HD 1080x1920 mockups. User-device screenshot and install testing still required. APK built with Android SDK 35/Gradle 8.9/JDK 17 through GitHub Actions.
