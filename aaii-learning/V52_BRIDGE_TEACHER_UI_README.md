# AAII Learning V5.2 — Native APK UI update

Build upon V5.1, recreating key elements of supplied navy/gold mockups as interactive native views. Category provider page features gold text, navy gradient, HD crest, provider logos and course filters. Specialization program details show course modules (from local public catalog where matched), infographic Step Flow from Courses→Specialization→Coursera Certificate verification→Professional Skills/Portfolio→Career path. No certificate is guaranteed; 'bridge' explains learning route, it is not automatic conversion to another issued credential. Private 353 certificate URLs must be imported from user-owned JSON; public GitHub code does not store them. Coursera organization Certificates link remains; may require authentication.

Teacher Request in Services now includes Name, Phone, Email (optional), Subject, Program selector, Online/Offline/Hybrid, native Date & Time pickers, Budget, Message, Platform spinner, preview, confirm and opening of Viber, LINE, Telegram, Email or other app. Viber/Telegram clipboard paste and LINE share text still require explicit user Send; this app cannot deliver directly to a recipient without provider APIs. Email requires selecting contact. Request locally saved as draft; not delivery confirmation. Client-controlled pop animation and click sound retained. Accurate visual pixel identity to static generated mockups is not claimed. Android device installation, audio, and target app handoff not device-tested.
