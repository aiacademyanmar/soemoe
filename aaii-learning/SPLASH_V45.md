# AAII Learning V4.5 Splash Screen

Uses user-selected global professional navy-and-gold crest artwork from the AAII Learning splash preview, resized to 160px width WebP for an offline asset and fast cold startup. Source artwork remains unchanged outside this app asset. `SplashActivity` is Android LAUNCHER and opens `MainActivity` after 2300 ms; no networking. The full-sized mockup is not included, and reduced resolution can look soft on large phone screens. Previous features remain including 337 Courses, Specializations, Certificates, teacher booking and Viber/LINE/Telegram contacts.
