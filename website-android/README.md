# Soe Moe AI Trainer V1.1
Native Android Kotlin WebView shell for https://soemoe.aaii.asia/.
Requires internet; not a fully offline or fully rewritten native content app.
Android Studio / Gradle 8.10.2 / JDK17 / Android SDK35.
CI debug APK is NOT a signed production release or device-tested build.
Original Kid Creator app in repository root remains unchanged. This app is isolated under website-android/.

Teacher portrait is bundled as a local Android image in the native app header. Tap image to enlarge. Tap toolbar title to toggle the header. Website HTML itself is unchanged. Previous debug signing keys may differ, requiring uninstall before reinstall.
