# Buddha Psychology V5.0 compiled preview
This independent preview recovers the offline PDF, nine MP3s, book text, 500 chapter outlines, and original Buddha images at build time from GitHub artifact run 41144156116. It is NOT the original APK UI, nor the earlier full V5.0 source, and it does not issue official certificates or show live ads without server configuration.
Build uses Java 17 / Android SDK 35 / AGP 8.7.3 / Gradle 8.9.
