# Dhamma Light Native Android v1.0
Native Kotlin + Jetpack Compose Android demonstration.

Build via .github/workflows/dhamma-light-native-v1.yml on branch dhamma-light-native-v1.
Project folder: dhamma-light.
Use GitHub Actions artifact "Dhamma-Light-Native-V1-APK" after a green build.
Source includes native Home, Stories (sample only), Watch, Sponsor, Academy, Impact and Settings screens.
YouTube: https://www.youtube.com/@knowledgezoneai
TikTok: https://www.tiktok.com/@aisoemoe
Sponsor is a calculator and share intent only, not a payment gateway.
App symbol is a vector implementation of the existing gold Dharma wheel logo.
