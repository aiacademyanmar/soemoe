# ပဋ္ဌာန်း အလင်း — Android V1.0
This branch is dedicated to building the Patthana native Kotlin/Jetpack Compose Android APK without modifying the main branch.

- 24 conditions (Paccaya) with Pali and Burmese explanations.
- Built-in 40-page A5 offline image reader.
- Media3 audio player for user-provided MP3 files and licensed HTTPS hosting.
- Source links to original Abhidhamma recordings; no third-party MP3 bytes redistributed.
- Use GitHub Actions to build the APK and download the build artifact.

Source archive: Patthana_Source_V1.tar.xz
